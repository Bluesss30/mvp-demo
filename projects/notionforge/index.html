手動建立步驟指南 ▶

如果偏好手動建立，依照以下步驟操作：

  1. 前往 Notion My Integrations，建立 Integration 並取得 Token
  2. 在 Notion 中開啟目標頁面 → 右上角「...」→「新增連線」→ 選擇你的 Integration
  3. 複製頁面 URL 中的 ID（最後的 32 位英數字元）
  4. 切換到「JSON」分頁，複製結構
  5. 根據 JSON 結構手動建立資料庫和欄位
